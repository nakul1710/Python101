🧑‍💻 Getting Started
1️⃣ Install Python

Download from 👉 https://www.python.org/downloads/

Check version:

python --version

2️⃣ Clone the Repository

git clone https://github.com/your-username/python101.git
cd python101

3️⃣ Create Virtual Environment

python3 -m venv project_name

4️⃣ Run Any Program

python filename.py
